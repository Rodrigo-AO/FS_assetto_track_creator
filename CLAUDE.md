# Assetto Track Creator

La documentación del proyecto vive en Obsidian: lee primero
`C:\Obsidian\vault\04 - Memoria Claude\assetto_track_creator\ASSETTO TRACK CREATOR.md` (nota central)
y las notas enlazadas del área que vayas a tocar. Al terminar una tarea, actualiza esas notas y
`Registro de cambios ATC.md`.

- Comandos: `npm run dev` · `npm test` · `npm run typecheck` · `npm run build`.
- La lógica va en `src/domain` y `src/export` (pura y con tests); la UI (`src/ui`) solo encadena acciones.
- Textos de UI y comentarios en español; identificadores en inglés.
